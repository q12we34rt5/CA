第 0 章 · 基礎

先換腦袋：Verilog 不是「程式」，是「電路的文字版」

寫 C 或 Python 時，你在描述一連串要依序執行的步驟。寫 Verilog 時，你在描述一堆同時存在的元件，以及它們之間怎麼接線。Verilog 屬於 HDL（Hardware Description Language，硬體描述語言），合成工具會把它翻譯成邏輯閘和正反器。

示意範例
assign x = a & b;
assign y = x | c;
assign z = ~y;

整份課程只需要記住兩種硬體：

  • 組合邏輯 (combinational logic)：輸出只由「現在的輸入」決定，沒有記憶。邏輯閘、加法器、多工器 (mux) 都是。
  • 循序邏輯 (sequential logic)：有 clk，會在時脈邊緣把值「記住」。就是正反器 (flip-flop) 與由它組成的暫存器。

lab1 裡所有可合成的程式碼，最後都只會變成這兩種東西加上導線。後面每一章就是在回答：「這個語法會變成哪一種？長什麼樣子？」

第 1 章 · 基礎

module 與 port：一顆有接腳的黑盒子

module 是 Verilog 的基本單位，對應到硬體就是一顆 IC 或電路板上的一個方塊。括號裡列出的是它的接腳 (port)：input 是訊號進來的腳，output 是訊號出去的腳。

riscvstall/riscvstall-CoreDpathAlu.v · 第 120–135 行
module riscv_CoreDpathAluLogical
(
  input  [1:0]  logical_fn, // 00 = and, 01 = or, 10 = xor, 11 = nor
  input  [31:0] alu_a,
  input  [31:0] alu_b,
  output [31:0] result
);

  assign result = ... ;     // 內部電路，第 4 章會打開來看

endmodule

module … endmodule 只是「設計圖」。真的要用到這顆電路時，要在別的 module 裡把它例化 (instantiate)，這在第 10 章說明。

wire vs reg：最容易誤會的名字

wire 就是導線，用 assign 驅動。reg 不等於暫存器，它只是語法規定：「在 always 區塊裡被賦值的訊號，必須宣告成 reg」。它最後變成什麼硬體，要看 always 的寫法：

宣告在哪裡被賦值合成結果lab1 的例子
wireassign組合邏輯的輸出線wire [31:0] sum = alu_a + xB;
regalways @(*)還是組合邏輯（沒有正反器！）AddSub 的 output reg [31:0] result
regalways @(posedge clk)真正的 D 正反器reg [31:0] pc_Fhl;

另外，wire [31:0] sum = alu_a + xB; 這種「宣告時順便給值」的寫法，等同於先 wire [31:0] sum; 再 assign sum = alu_a + xB;，lab1 大量使用。

32'b???????_?????_…_0110111? 是 casez 用的萬用字元；_ 只是方便閱讀的分隔InstMsg 的指令編碼
31（沒寫寬度）預設 32 位元十進位。能用，但寬度不明確時容易有警告乘法器 counter 的初值
為什麼每個 mux 最後都接 32'bx？

像 ( sel == 2'd0 ) ? a : ( sel == 2'd1 ) ? b : 32'bx。這是 lab1 作者的習慣：如果 sel 出現了不該出現的值，模擬波形上會立刻冒出紅色的 x，幫你抓 bug；對合成工具來說 x 表示「隨便」，讓它有更多化簡空間。
