第 7 章 · 循序邏輯

always @(posedge clk)：長出 D 正反器

到目前為止的電路都沒有記憶。要「記住」東西，需要 D 正反器 (D flip-flop)：它只在 clk 從 0 變 1 的那一瞬間（上升緣，posedge）看一眼輸入 D，把值抄到輸出 Q，其餘時間 Q 完全不動。

vc/vc-StateElements.v · 第 14–24 行
module vc_DFF_pf #( parameter W = 1 )
(
  input              clk,
  input      [W-1:0] d_p,
  output reg [W-1:0] q_np
);
  always @( posedge clk )
    q_np <= d_p;
endmodule

這就是為什麼同步電路好設計：組合邏輯在兩個上升緣之間可以亂跳、慢慢算，只要在下一個上升緣前穩定下來就好。

reset 和 enable：只是在 D 前面多一顆 mux

vc/vc-StateElements.v · 第 38–39 行、第 55–56 行
// vc_RDFF_pf                             // vc_EDFF_pf
always @( posedge clk )                   always @( posedge clk )
  q_np <= reset_p ? RESET_VALUE : d_p;      if ( en_p ) q_np <= d_p;

lab1 的 datapath 把兩者合在一起用。下面這段就是「有 reset、有 enable 的 32 位元暫存器」，!stall_Fhl 扮演 enable 的角色：

riscvstall/riscvstall-CoreDpath.v · 第 126–135 行
reg  [31:0] pc_Fhl;

always @ (posedge clk) begin
  if( reset ) begin
    pc_Fhl <= reset_vector;            // reset 優先
  end
  else if( !stall_Fhl ) begin
    pc_Fhl <= pc_mux_out_Phl_final;    // 沒 stall 才更新
  end                                  // 否則：保持原值
end
同步 vs 非同步 reset

lab1 全部使用同步 reset：敏感列表只有 posedge clk，reset 只是 D 前面的一顆 mux，要等到上升緣才生效。你在別處可能看到 always @(posedge clk or posedge reset)，那是非同步 reset，會用到正反器上專用的 reset 腳。

Latch 與 flip-flop 的差別：vc-StateElements.v 後半的 vc_Latch_hl 是 latch——只要 clk 為高，輸出就一路跟著輸入變（透明）；flip-flop 只在邊緣那一瞬間取樣。lab1 的處理器本體只用 flip-flop。

第 8 章 · 循序邏輯

= 與 <=：blocking 與 non-blocking

Verilog 有兩種賦值符號，差別只在同一個 always 區塊裡有多行的時候才看得出來：

  • =（blocking）：像軟體一樣，這行做完才做下一行，下一行看到的是新值。
  • <=（non-blocking）：所有右邊的值在時脈邊緣同時取樣，然後全部一起更新。這正是一排真實正反器的行為。
示意範例
always @(posedge clk) begin        always @(posedge clk) begin
  b <= a;                            b = a;
  c <= b;   // 用的是「舊的」b        c = b;    // 用的是「剛更新的」b，也就是 a
end                                end
lab1 遵守的鐵則（你也照做就對了）

always @(posedge clk) 裡面一律用 <=；always @(*) 裡面一律用 =。不要在同一個區塊混用。

你可以在 riscvstall-CoreDpath.v 驗證：pc_Dhl <= pc_Fhl;（第 156 行）與 pc_Xhl <= pc_Dhl;（第 244 行）寫在不同的 always 區塊，但因為都用 <=，在同一個上升緣，pc_Xhl 拿到的一定是 pc_Dhl 的舊值——PC 才會乖乖地每個週期往下一級管線移動一格。

第 9 章 · 循序邏輯

記憶體陣列：Register File

reg [31:0] registers[31:0]; 有兩個範圍：名字前面的 [31:0] 是每一格的寬度，名字後面的 [31:0] 是有幾格。所以這是 32 個 32 位元暫存器，也就是 RISC-V 的 x0–x31。

riscvstall/riscvstall-CoreDpathRegfile.v · 第 20–32 行
reg [31:0] registers[31:0];

// Combinational read ports
assign rdata0 = ( raddr0 == 0 ) ? 32'b0 : registers[raddr0];
assign rdata1 = ( raddr1 == 0 ) ? 32'b0 : registers[raddr1];

// Write port is active only when wen is asserted
always @( posedge clk )
begin
  if ( wen_p && (waddr_p != 5'b0) )
    registers[waddr_p] <= wdata_p;
end

小型陣列會像上圖一樣用正反器實作。大型記憶體（例如 vc-TestDualPortMem.v 裡 1 MB 的測試記憶體）在真實晶片上會換成專用的 SRAM 區塊；在 lab1 裡它只用於模擬，不需要合成。
