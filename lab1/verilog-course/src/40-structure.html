第 10 章 · 組織大型設計

模組例化、parameter 與 localparam

定義好 module 之後，在別的 module 裡「放一顆」就叫例化 (instantiate)。語法是 模組名 實例名 ( .port名(接到哪條線), … );。這不是函式呼叫——每例化一次，晶片上就多一份實體電路。

riscvstall/riscvstall-CoreDpathAlu.v · 第 230–276 行（節錄）
wire [31:0] addsub_out;

riscv_CoreDpathAluAddSub addsub     // 模組名  實例名
(
  .addsub_fn  (fn_addsub),          // .模組內的 port 名 (外面的線)
  .alu_a      (in0),
  .alu_b      (in1),
  .result     (addsub_out)
);

riscv_CoreDpathAluShifter shifter
(
  .shift_fn   (fn_shifter),
  .alu_a      (in1),                // 注意：shifter 的 a、b 接法是反的
  .alu_b      (in0),
  .result     (shifter_out)
);
// ... logical、muldiv 同理 ...

assign out = ( out_mux_sel == 2'd0 ) ? addsub_out
           : ( out_mux_sel == 2'd1 ) ? shifter_out
           : ( out_mux_sel == 2'd2 ) ? logical_out
           : ( out_mux_sel == 2'd3 ) ? muldiv_out
           :                           32'bx;

port 也可以故意不接：CoreDpath.v 第 386 行的 .opcode () 括號裡是空的，表示這個輸出懸空不用，合成工具會把產生它的邏輯一併刪掉。

parameter：可調整的設計圖

定義：vc/vc-StateElements.v 第 30 行　使用：Testbench.v 第 87–94 行
// 定義時：#( ) 裡列出參數和預設值
module vc_RDFF_pf #( parameter W = 1, parameter RESET_VALUE = 0 )
( input clk, input reset_p, input [W-1:0] d_p, output reg [W-1:0] q_np );

// 例化時：在模組名和實例名之間，用 #( .參數名(值) ) 覆寫
Pattern
#(
  .p_max_delay    (`PATTERN_MAX_DELAY),
  .p_reset_cycles (`PATTERN_RESET_CYCLES)
)
pattern
( .clk (clk), ... );

parameter 在合成之前就被代換成常數，所以 vc_RDFF_pf #(.W(32)) 和 #(.W(5)) 會產生兩種不同大小的電路。這無法畫成一張圖——它決定的是「圖要畫多大」。

localparam 是不能從外面覆寫的常數，lab1 用它來幫「魔術數字」取名字，讓控制表格讀得懂：

第 11 章 · 組織大型設計

`define、`include、`ifndef 與 casez

反引號 ` 開頭的是編譯器指令，和 C 的 #define、#include、#ifndef 幾乎一模一樣：在真正解析 Verilog 之前做純文字代換。它們本身不產生任何電路，所以這一節沒有電路圖，只有被代換之後的結果才有。

riscvstall/riscvstall-InstMsg.v · 第 57–68 行、第 277 行
`ifndef RISCV_INST_MSG_V        // include guard：避免同一個檔案被引入兩次
`define RISCV_INST_MSG_V

`define RISCV_INST_MSG_OPCODE   6:0       // 巨集可以是任何文字，連 "6:0" 都行
`define RISCV_INST_MSG_RD       11:7

assign opcode = msg[ `RISCV_INST_MSG_OPCODE ];   // 展開後就是 msg[6:0]
assign rd     = msg[ `RISCV_INST_MSG_RD ];       //             msg[11:7]
...
`endif
指令作用注意
`define NAME 文字定義巨集。也可以帶參數，如 `define VC_MEM_REQ_MSG_SZ(a,d)使用時也要加反引號：`NAME
`include "file.v"把另一個檔案的內容整個貼進來lab1 每個檔案頂端都靠它引入相依模組
`ifndef / `ifdef / `elsif / `else / `endif條件編譯Testbench.v 用它在三種處理器實作之間切換
`ifndef SYNTHESIS只在模擬時存在的程式碼（反組譯器、assertion）合成時會定義 SYNTHESIS 把它們排除

`define 與 parameter 怎麼選？ `define 是全域的純文字代換，跨檔案共用（例如指令編碼）；parameter / localparam 屬於某個 module、有型別、每個實例可以不同。

casez：帶萬用字元的 case

處理器要從 32 位元的指令判斷「這是哪一道指令」。不同指令要看的位元不一樣，casez 允許用 ? 表示「這一位不用比」。

riscvstall/riscvstall-InstMsg.v 第 122 行 ＋ riscvstall-CoreCtrl.v 第 411–418 行
`define RISCV_INST_MSG_ADDI  32'b???????_?????_?????_000_?????_0010011

casez ( ir_Dhl )
  `RISCV_INST_MSG_LUI  : cs = { y, n, br_none, pm_p, am_0,    n, bm_imm_u, ... };
  `RISCV_INST_MSG_ADDI : cs = { y, n, br_none, pm_p, am_rdat, y, bm_imm_i, ... };
  ...
endcase

第 12 章 · 組織大型設計

generate for：複製貼上電路的迴圈

這裡的 for 和軟體迴圈完全不同：它不會在執行時跑 N 次，而是在合成前被展開，把迴圈本體複製 N 份，每份的 i 是不同的常數。迴圈變數要用 genvar 宣告。

vc/vc-RAMs.v · 第 71–81 行
genvar i;
generate
  for ( i = 0; i < ENTRIES; i = i+1 )
  begin : wport                          // 每一份複本的名字：wport[0]、wport[1]…
    always @( posedge clk )
      if ( reset_p )
        mem[i] <= RESET_VALUE;
      else if ( wen_p && (i == waddr_p) )
        mem[i] <= wdata_p;
  end
endgenerate

generate 裡的迴圈上限必須是合成時就知道的常數（parameter 或數字），因為電路的份數不可能在晶片做好之後才決定。
