RISC-V CPU 圖解課

進階篇：從指令集到 lab1 的五級管線、bypass 與長管線

章節目錄

    從一道 RISC-V 指令，到一顆會跑 C 程式的管線 CPU

    這是《Verilog 電路圖解課》的進階篇。基礎篇教你「一行 Verilog 是什麼電路」；這一篇回答另一個問題：這些電路為什麼要這樣接？我們從 RISC-V 指令集開始，跟著指令走過 lab1 的五級管線，看懂 stall、squash、bypass，最後接上管線式乘除法器——正好對應作業的四個 Objective。

    範例一律取自 lab1/lab1 的原始碼並附檔名與行號；標示 示意範例 的是為了說明另外寫的。行號以發下來的原始檔為準——你自己改過檔案之後，後面的行號會跟著往下移。想查某條線實際接到哪裡，可以搭配管線接線圖與符號查詢一起看。

    • 資料線
    • 控制訊號
    • 重點路徑（本圖要你看的那條）
    • 暫存器／管線暫存器
    • 組合邏輯
    • bubble（空的一格）
